### C-01. 가정: 비동기 이미지 분석 결과에 대해 사용자가 판정이 맞는지 확인하고 의견을 남길 수 있도록 `reviews` 테이블을 추가하려고 합니다. 이 테이블은 어떤 데이터를 저장해야 하며, 기존 프로젝트의 어떤 파일들을 수정해야 하나요?


모범답변

`reviews` 테이블은 AI가 예측한 결과가 실제로 맞았는지 사용자가 검토한 내용을 저장하기 위한 테이블입니다.

예를 들어 AI가 콩잎을 `healthy`로 예측했지만 실제로는 `bean_rust`였다면, 사용자가 올바른 정답과 검토 의견을 기록할 수 있습니다. 이러한 기록은 추후 오분류 분석과 모델 개선에 활용할 수 있습니다.

|파일|추가 또는 수정할 내용|
|---|---|
|`ai/models.py`|`Review` ORM 모델 및 `image_jobs`와의 관계 정의|
|`ai/database.py`|새로운 ORM 모델이 테이블 생성 대상에 포함되는지 확인|
|`ai/router_async.py` 또는 신규 `ai/router_reviews.py`|리뷰 등록·조회·수정·삭제 API 구현|
|`main.py`|신규 라우터를 만들었다면 등록|
|`templates/async.html`|분석 결과에 대한 검토 의견 입력 및 조회 기능 추가|

`reviews` 테이블에는 `id`, `job_id`, `review_label`(사용자가 확인한 실제 클래스), `comment`(검토 의견), `created_at` 등의 필드를 둘 수 있습니다.

특히 `job_id`를 외래 키(Foreign Key)로 사용하여 기존 `image_jobs`의 분석 결과와 리뷰 내용을 연결하겠습니다.

추가 확인 질문

1. `image_jobs`와 `reviews` 테이블을 분리하는 이유는 무엇인가요?
    
2. 두 테이블을 연결할 때 어떤 필드를 외래 키로 사용하겠습니까?
    
3. 사용자가 기존 리뷰를 수정하거나 삭제할 수 있게 하려면 어떤 API를 추가해야 하나요?
    
4. 새 테이블을 추가한 뒤 PostgreSQL에서 정상적으로 생성되었는지 어떻게 확인하겠습니까?
